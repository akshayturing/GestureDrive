About GestureDrive

Project Overview

GestureDrive is a system that enables control of devices using hand gestures captured through a webcam. The system uses computer vision techniques to recognize hand positions and movements, translating them into control commands.

How It Works

  • Image Capture: Your webcam captures video frames in real-time
  • Hand Detection: MediaPipe library identifies hand positions in each frame
  • Gesture Recognition: Machine learning algorithms recognize specific gesture patterns
  • Command Execution: Recognized gestures are translated into control commands

Technologies Used

  • OpenCV: For webcam access and image processing
  • MediaPipe: For hand landmark detection and gesture recognition
  • Flask: For the web interface
  • NumPy: For array operations and data manipulation
